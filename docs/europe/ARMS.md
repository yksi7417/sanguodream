# The coats of arms of 1200

This document lists one coat of arms for each of the 30 factions of the
game of 1200. It is the list for the external work on the arms
(docs/EUROPE.md, E5). docs/europe/arms.tsv has the same list with the
direct URL of each file.

## The licences
- 23 files are in the public domain or have the licence CC0. The game can
  use them with no credit.
- Leon, Portugal and Cyprus have a CC BY-SA file and a public-domain choice.
  The choice of Cyprus is a photograph of a later relief at Kolossi.
- Bulgaria and Sicily have only CC BY-SA files. A CC BY-SA image needs the
  author and the licence in the credits. A changed image keeps the licence.
- Staufer and Welf have the licence "Attribution". The credits must name
  David Liuzzo.
- The game uses no CC BY-SA image. The images of the game come from the
  Drive folder, and Google Gemini made them (question Q-E3, closed on
  2026-10-30).

## The dates of the arms
Heraldry started in western Europe in the 12th century. Some arms in the
list are later than 1200. The column "period" of arms.tsv gives the date
of each file.
- These arms are from 1200 or before: France, Angevin, Toulouse, Aragon,
  Castile, Leon, Portugal, Welf, Hungary, Flanders and Denmark.
- These arms are later attributions: Byzantium, Bulgaria, Rum, Sicily,
  Poland, the papacy and Venice.
- The Almohads, the Banu Ghaniya and the Ayyubids used banners, not arms.
  The files are modern drawings of these banners.
- The Abbasids also used a banner. The file is a modern picture.
- Nobody checked the date of the files of Jerusalem, Antioch, Cilicia,
  Cyprus and Georgia. The column "period" says so. A later step must
  check these dates.

## The files from the Drive folder
The external work puts the images in a shared Google Drive folder. A later
step of E5 imports them into data/medieval_europe/arms.
- Give each image the force key as its name, for example france.svg or
  france.png.
- Give an SVG file, or a PNG file of 512 x 512 pixels or more with a
  transparent background.
- Put a file sources.tsv in the folder. Give one row for each image with
  these columns: key, source_url, licence, author.
- If a person or a tool made a new image, give its name in the column
  author. Give the licence that the person or the tool permits.

On 2026-10-30, misc/arms_import.py imported the 30 images of the folder:
first 24, then the six of the prompts below. Each faction now has arms. To
replace an image, put the new file in the folder and in a local folder,
then run the tool again on the local folder:

    python -X utf8 -E -P misc\arms_import.py FOLDER

The tool crops each image to its solid shape and puts the shape in the
centre of the square. Add the row of each new file to
data/medieval_europe/arms/sources.tsv.

## The prompts for the last six arms
These prompts made the images of Jerusalem, Antioch, Cilicia, Cyprus,
Georgia and the Abbasids in the style of the first 24 images of the folder. Give the common text first, then the text of the faction.
Name each file with the key, for example jerusalem.png.

The common text:

    A flat vector heraldic image for a strategy game, 1024 x 1024 pixels,
    on a fully transparent background. Flat colours only: no shading, no
    gradients, no texture, no 3D bevel, no metal effect. A thin dark
    brown outline around the shape. No text, no letters, no crown above
    the shape, no supporters, no motto, no frame. The shape fills the
    image and is centred.

After you make the images:
1. Put the six files in the Drive folder.
2. Add six rows to sources.tsv in the folder, with the URL of the Gemini chat.
3. Tell Claude to import them, or run misc/arms_import.py yourself.

The result: each faction of the east map shows its arms on the flags.
